# diffusion-toxin-benchmark
Code and analysis scripts accompanying our paper on how likely diffusion-based de novo protein design pipelines (RFdiffusion, ProteinMPNN, ESM Inverse Folding, ESM-2 and ColabFold) are to propose known toxins, assessed by structural (TM-score) and sequence (Needleman-Wunsch) similarity to 20 PDB toxins.
